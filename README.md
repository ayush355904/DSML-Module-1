🇮🇳 COVID-19 Data Analysis in India
A Python-based Data Analysis / EDA project that analyzes COVID-19 cases across Indian states and union territories.
📌 Features
- Data cleaning and inspection
- Missing value & duplicate checking
- State-wise COVID-19 analysis
- Confirmed, recovered, active cases and deaths
- Recovery Rate & Death Rate calculation
- Top 10 affected states
- Data visualization using charts
🛠️ Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- KaggleHub
- Google Colab / Jupyter Notebook
📊 Dataset
The project uses the COVID-19 India dataset and mainly analyzes covid_19_india.csv.
Dataset contains 18,110 records and 9 columns.
▶️ How to Run
Install required libraries:
pip install pandas numpy matplotlib seaborn kagglehub
Open Untitled3.ipynb in Google Colab or Jupyter Notebook and run the cells from top to bottom.
📈 Analysis
The project calculates:
- Active Cases
- Recovery Rate
- Death Rate
- State-wise confirmed cases
- State-wise deaths
- Daily confirmed-case trends
